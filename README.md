# RIFT Hotel prototype

A static five-page website prototype for the RIFT Hotel digital marketing assignment.

## Pages
- `index.html` — home / landing page
- `stay.html` — accommodation / offer
- `experiences.html` — experience / differentiator
- `location.html` — location, trust and practical decision support
- `book.html` — mock booking / conversion destination

This is a fictional hotel concept and no real reservations are created.

The project is designed for GitHub Pages and requires no build process, database, paid hosting, or custom domain.
